# Remaining human playtest

The automated balance and browser reports cover reproducible behavior. This short session checks whether the resulting choices are understandable and enjoyable.

## Map pacing (about five minutes)

The user has already compared difficulty in the development preview and reported: “Hard feels more challenging and fair.” The remaining request is broader pacing and device coverage.

1. Choose **Set up a match → Player vs Computer → First to 1**. Try **Quick Draw**, then **Brick by Brick**, using the same difficulty. The first is intended to produce early contact; the second requires more demolition. Note whether either feels like waiting rather than making useful decisions.
2. Note whether you understand why you died and whether you could see an escape route. A tougher opponent should not feel like it has different movement or bomb rules.
3. Report any repeated running in circles, standing still while an attack is available, obviously suicidal plants, or confusing special-item actions. Include the map, theme and difficulty. The pause menu can export a replay record for diagnosis; it stays local unless you choose to share it.

Useful feedback is a concrete moment: “Hard stood beside the same wall for ten seconds” or “I could not tell why that chain reached me.” Also note whether you wanted another round.

## Device checks when the hardware is available

- Two humans on one keyboard: hold both players' movement keys while planting bombs; verify neither player loses input. Keyboard rollover cannot be established with simulated key events.
- Actual controllers: try keyboard plus controller and two controllers; disconnect and reconnect one during a round. Confirm the game pauses and controls return to the intended player.
- A real iPhone or Android phone: try movement plus Bomb at the same time, rotate the screen, switch apps and return, and check sound after resuming. Report the device and browser and any sustained stutter or unreadable hazards.

The original game installation and maps are unavailable. Exact original-rule compatibility, original map coverage and dud behavior remain separate reference-evidence gaps; this playtest does not certify them.
